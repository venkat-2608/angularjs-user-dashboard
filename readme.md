# AngularJS User Dashboard

A dynamic user dashboard built using AngularJS demonstrating core concepts such as data binding, form validation, state management, and custom directives.

---

## 🚀 Features

- Two-way data binding using `ng-model`
- AngularJS form validation (`$valid`, `$touched`, `$invalid`)
- Live preview of user input
- State management with submitted user tracking
- Reset functionality for form handling
- Conditional rendering using `ng-if`
- Custom directive for reusable user display component

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- AngularJS (v1.8)

---

## 📂 Project Structure

- index.html   → Main UI structure  
- app.js       → AngularJS logic (controller + directive)  
- style.css    → Styling
